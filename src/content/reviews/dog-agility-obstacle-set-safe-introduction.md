## Verify the equipment

Ask for the full parts list, tunnel dimensions, pole height, base design, and instructions for securing each obstacle. Check whether the kit is intended for indoor or outdoor use and how it should be anchored. Make sure the practice area has a non-slip surface, ample clearance, and no nearby sharp furniture.

## Introduce movement safely

Start with walking through a stationary tunnel or stepping over a low obstacle, using rewards and a calm pace. Do not force the dog through equipment. Avoid high jumps or repeated impact, especially for puppies, seniors, or dogs with joint or mobility concerns; consult a veterinarian if uncertain. Inspect poles and connectors before every session.

## Bottom line

This is enrichment equipment, not a requirement for exercise. Choose a kit only if the dog enjoys it and you can set it up securely.
